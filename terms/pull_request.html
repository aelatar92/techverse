Pull Request

PR · Merge Request

AR · العربية

طلب رسمي لدمج التغييرات من فرع إلى آخر، يتيح لبقية الفريق مراجعة الكود والتعليق عليه قبل الموافقة على الدمج.

EN · English

A formal request to merge changes from one branch into another, letting the rest of the team review and comment on the code before approving the merge.
