Web Browser

Browser

AR · العربية

برنامج يتيح للمستخدم تصفح صفحات الويب وعرضها، عبر إرسال طلبات HTTP/HTTPS للخوادم وعرض المحتوى الناتج (HTML/CSS/JS)، مثل Chrome وFirefox.

EN · English

A program that lets users browse and view web pages by sending HTTP/HTTPS requests to servers and rendering the resulting HTML/CSS/JS content, such as Chrome or Firefox.
