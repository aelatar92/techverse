WPS

Wi-Fi Protected Setup

AR · العربية

ميزة تسهّل ربط الأجهزة بشبكة Wi-Fi عبر ضغط زر أو رمز PIN بدل كتابة كلمة المرور، لكنها معروفة بثغرات أمنية جعلت تعطيلها ممارسة أمان موصى بها.

EN · English

A feature that simplifies joining a Wi-Fi network via a button press or PIN instead of typing the password; it has known security flaws, and disabling it is a recommended best practice.
