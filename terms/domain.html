Domain Name

Domain

AR · العربية

الاسم القابل للقراءة الذي يمثل موقعًا على الإنترنت (مثل example.com)، ويترجمه DNS إلى عنوان IP يفهمه الحاسوب.

EN · English

The human-readable name that represents a website (like example.com); DNS translates it into the IP address computers understand.
