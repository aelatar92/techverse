macOS

Mac OS X · OS X

AR · العربية

نظام تشغيل أبل المخصص لأجهزة Mac، مبني على أساس Unix، ويجمع بين واجهة استخدام رسومية سهلة وأدوات سطر أوامر شبيهة بلينكس.

EN · English

Apple's operating system for Mac computers, built on a Unix foundation; it combines an easy graphical interface with Linux-like command-line tooling.
