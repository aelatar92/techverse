CPU Cache

L1 Cache · L2 Cache · L3 Cache

AR · العربية

ذاكرة صغيرة فائقة السرعة داخل المعالج أو قريبة منه، تخزّن البيانات الأكثر استخدامًا لتقليل زمن الوصول مقارنة بالذاكرة العشوائية، وتُقسّم عادة لمستويات L1/L2/L3.

EN · English

A very fast, small memory built into or close to the CPU that stores frequently used data to reduce access time compared to RAM; typically split into L1/L2/L3 levels.
