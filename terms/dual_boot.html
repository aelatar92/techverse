Dual Boot

Multi-boot

AR · العربية

إعداد يسمح بتثبيت أكثر من نظام تشغيل على نفس الجهاز، ويختار المستخدم النظام المطلوب تشغيله عند بدء التشغيل عبر قائمة إقلاع.

EN · English

A setup that lets more than one operating system be installed on the same machine, with the user choosing which one to boot via a startup menu.
