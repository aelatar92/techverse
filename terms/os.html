Operating System

OS

AR · العربية

البرنامج الأساسي الذي يدير موارد الجهاز (المعالج، الذاكرة، التخزين) ويوفّر بيئة لتشغيل البرامج الأخرى فوقه.

EN · English

The core software that manages a device's resources (CPU, memory, storage) and provides an environment for other software to run on top of it.
