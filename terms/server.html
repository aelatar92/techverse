Server

AR · العربية

جهاز أو برنامج يقدّم خدمة أو موارد لأجهزة أخرى (العملاء) عبر الشبكة، مثل خادم ويب أو خادم قواعد بيانات.

EN · English

A device or program that provides a service or resources to other devices (clients) over a network, such as a web server or database server.
