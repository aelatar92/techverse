Code Review

AR · العربية

عملية يفحص فيها مطوّر آخر تغييرات الكود قبل دمجها، للتأكد من جودتها وصحتها واتساقها مع معايير المشروع.

EN · English

The process where another developer examines code changes before they're merged, checking quality, correctness, and consistency with project standards.
