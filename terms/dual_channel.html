Dual-Channel Memory

Multi-Channel Memory

AR · العربية

تقنية تشغّل عصا ذاكرتين (أو أكثر) معًا كمسارين متوازيين لمضاعفة عرض النطاق الترددي للذاكرة مقارنة بعصا واحدة (Single-Channel).

EN · English

A technique that runs two (or more) memory sticks together as parallel channels, roughly doubling memory bandwidth compared to a single stick.
