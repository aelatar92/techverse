CPU Core

Multi-core · Processor Core

AR · العربية

وحدة معالجة مستقلة داخل المعالج قادرة على تنفيذ التعليمات بمفردها؛ المعالجات الحديثة تحتوي على عدة أنوية (Multi-core) لتنفيذ مهام متعددة بالتوازي.

EN · English

An independent processing unit within a CPU capable of executing instructions on its own; modern processors pack multiple cores to run tasks in parallel.
