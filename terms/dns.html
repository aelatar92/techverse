DNS

Domain Name System

AR · العربية

نظام أسماء النطاقات، يترجم أسماء المواقع القابلة للقراءة (مثل google.com) إلى عناوين IP يفهمها الجهاز.

EN · English

The Domain Name System (RFC 1035) translates human-readable domain names, such as google.com, into the IP addresses machines use to communicate.
