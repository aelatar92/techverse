DOM

Document Object Model

AR · العربية

تمثيل شجري لصفحة HTML يبنيه المتصفح في الذاكرة، يتيح للغات مثل JavaScript قراءة محتوى الصفحة وتعديله ديناميكيًا.

EN · English

A tree-like representation of an HTML page that the browser builds in memory, letting languages like JavaScript read and dynamically modify the page's content.
