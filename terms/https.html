HTTPS

HTTP Secure

AR · العربية

نسخة مشفّرة من HTTP تستخدم بروتوكول TLS لحماية البيانات المتبادلة بين المتصفح والخادم من التنصت والتلاعب.

EN · English

An encrypted version of HTTP that uses the TLS protocol to protect data exchanged between browser and server from eavesdropping and tampering.
