OSPF

Open Shortest Path First

AR · العربية

بروتوكول توجيه داخلي يحسب أقصر مسار لنقل البيانات داخل نفس الشبكة اعتمادًا على حالة الروابط.

EN · English

An interior gateway routing protocol (RFC 2328) that calculates the shortest path for data within a network based on link-state information.
