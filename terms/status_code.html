HTTP Status Code

404 · 500

AR · العربية

رمز رقمي يرسله الخادم مع كل استجابة HTTP ليخبر المتصفح بنتيجة الطلب، مثل 200 (نجاح)، 404 (غير موجود)، أو 500 (خطأ في الخادم).

EN · English

A numeric code the server sends with every HTTP response to tell the browser the outcome of the request, such as 200 (OK), 404 (Not Found), or 500 (Server Error).
