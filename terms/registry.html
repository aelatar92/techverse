Windows Registry

Registry

AR · العربية

قاعدة بيانات هرمية مركزية في ويندوز تخزّن إعدادات النظام والتطبيقات والمستخدمين، وتعادل تقريبًا مجلد /etc في لينكس.

EN · English

A centralized, hierarchical database in Windows that stores system, application, and user settings — roughly the Windows counterpart to the /etc directory on Linux.
