Microservices

AR · العربية

أسلوب معماري يُقسّم التطبيق إلى خدمات صغيرة مستقلة، كل واحدة مسؤولة عن وظيفة محددة وتتواصل مع البقية عبر APIs.

EN · English

An architectural style that splits an application into small, independent services, each responsible for a specific function and communicating with the rest via APIs.
